Mismatch Planted Detected

Each tick is a shared position where the two strains differ. A recombined block is called only if its gap in ticks is long enough to pay for switching into the low state and back; an import is called when its ticks are dense enough. Detected blocks run from just after one mismatch to the mismatch that closes them, so their edges snap to the nearest mismatches.

Evidence for an identical run

Gain of the low state over background Cost of entering and leaving a block Run holding a planted block (filled when found)

An identical run of g shared positions, closed by a mismatch, fits the low state better than background by g·[ln(1−rlow) − ln(1−d)] + ln(rlow/d). A run flanked by background is called only when that gain beats the cost of two switches, 2·[ln(1−s) − ln(s/2)]. Each dot is the run that holds a planted recombined block: the block plus the matches out to the nearest mismatch on each side. A run can still be called below the line when it borders another non-background block, because moving straight from high to low costs one switch, not two; that is how R3 is caught with Catch R3.
